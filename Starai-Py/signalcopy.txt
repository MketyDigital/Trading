StarPips Trade Copier & AI Engine - Feature List

1. Core Architecture (The "Split" Model)
The Listener (Azure VM / Python MTProto)already actuvely listening : Uses real Telegram account to silently listen to VIP provider channels where bots are not allowed. It uses almost zero RAM and instantly forwards the raw text to Cloudflare via Webhook.

The Brain (Cloudflare Edge Worker): A highly scalable, serverless engine that receives the webhook, queries the AI, applies the routing rules, and manages the logic.

The Broadcaster (Telegram BotFather): The Cloudflare Brain uses your official Telegram Bot to broadcast the finalized signals to your destination channels. This prevents your real Telegram account from getting banned for spam.

2. AI Formatting & Rebranding
Gemini AI, openai, etc, Parsing: Instantly reads messy, unstructured VIP signals (e.g., "buy gold now at 1950 sl 1940") and extracts the exact Symbol, Action, Entry, Stop Loss, and Take Profits.

Institutional Templates: Rebrands the extracted data into your own clean, professional, emoji-free template (e.g., Powered by StarPips).

Drag-and-Drop Ordering: You can easily define the order of the fields (e.g., Action first, then Symbol, then Entry).

3. Advanced Routing Matrix
Multi-Channel Mapping: Map signals visually. Supports 1:1 (Source A to Dest A), 1:N (Source A to Dest B, C, D), and N:1 routing.

Web Dashboard UI: A beautiful React-based dashboard where your manager can log in, add new channel IDs, and update the routing matrix without touching any code.

Permanent Cloud Storage: All settings and rules are saved securely via Supabase (or Cloudflare KV), preventing any data loss during server restarts.

4. Live Price Injection (Deriv / Forex)
Dynamic Entry Replacement: Before the signal is broadcasted, the Cloudflare brain can fetch the exact, real-time market price (via Deriv API or generic REST APIs).

Spread/Slippage Protection: If a VIP provider's entry price is outdated by the time they post it, the system automatically replaces it with the actual current market price so your users get accurate entry data.

5. Smart Reply & Trade Management
Reply Tracking: The system tracks the message_id of every signal it sends.

Follow-up Threading: If a VIP provider replies to an old signal saying "Close half" or "Move SL to Breakeven", the system finds the exact matching signal in your destination channel and replies to it directly as a threaded message.

6. Algorithmic Copy Trading (MT5 & Deriv)
Trade Execution Ready: The system parses the exact entry and exit parameters precisely so they can be fed into an algorithm.


MT5 Python Integration: Cloudflare can send a secure webhook back to your vps containing the extracted JSON data (Symbol: XAUUSD, Action: BUY, Lot: 0.01) to automatically execute the trade on a MetaTrader 5 terminal using the official MetaTrader5 Python library.(ready but yet to activate the mt5)
